# Septic Shock

Septic Shock is a turn-based educational strategy game where immune cells defend the body against invading pathogens using movement, combat, and card-based mechanics.

## Repository Structure
- `/board` → game board and layout assets
- `/immune-cells` → immune unit sprites and card images
- `/pathogens` → pathogen sprites and card images
- `/immune-support-cards` → beneficial immune system cards
- `/virulence-factor-cards` → pathogen advantage cards
- `/misc` → card backs and miscellaneous assets

## Naming Convention
All files follow:
- lowercase
- underscore-separated
- descriptive naming

## Usage
These assets are intended for use in a browser-based digital version of the Septic Shock board game.
